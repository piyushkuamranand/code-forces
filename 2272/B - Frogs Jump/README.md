It is guaranteed that <span class="tex-font-style-bf">each column</span> of the input grid contains <span class="tex-font-style-bf">at least one</span> frog. You can choose $$$k$$$ frogs and remove them from the grid. After this, all remaining frogs will jump.</p><p>Each frog can jump up, down, left, or right by $$$1$$$ cell, but cannot jump outside the grid.
